Stoic Uploader

Stoic Uploader là công cụ nội bộ dùng để đăng và quản lý video trên hai kênh YouTube về triết học Khắc Kỷ (Stoicism) của chúng tôi:

  • Bản Lĩnh Khắc Kỷ (tiếng Việt)
  • The Stoic Blueprint (English)

Công cụ dùng YouTube Data API để tải video lên, đặt lịch công khai, thêm ảnh thu nhỏ, phụ đề và danh sách phát; và YouTube Analytics API để xem số liệu của chính các kênh này. Công cụ không dành cho người dùng bên ngoài.

English

Stoic Uploader is an internal tool used to publish and manage videos on our two YouTube channels about Stoic philosophy, listed above. It uses the YouTube Data API to upload videos, schedule them, and set thumbnails, captions and playlists, and the YouTube Analytics API to read statistics for these channels only. It is not offered to the public.
